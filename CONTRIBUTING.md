# Contributing

Thanks for your interest in Weishu.

Weishu is an independently maintained fork of [RikkaHub](https://github.com/rikkahub/rikkahub).
Bug reports and pull requests are welcome.

## Ground rules

- Run `./gradlew test` before opening a pull request.
- For anything beyond a small fix, open an issue first so we can agree on the approach.
- Keep changes focused. Large, sweeping refactors are hard to review and are usually rejected.
- Do not remove or rewrite the license and attribution notices.

## Build

See the build section in [README.md](README.md). No `google-services.json` is required.
